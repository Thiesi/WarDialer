# War Dialer

An asynchronous multiplayer door game for BBSes: rival crews compete for ten
phone exchanges across a season, in one shared world that every caller on the
board plays.

War Dialer is moving here from [NetBBS](https://github.com/Thiesi/NetBBS), where
it ships bundled today. The plan is in Thiesi/NetBBS#1223, and the work is
tracked in this repository's issues: first its SysOp administration moves into
the door (Thiesi/NetBBS#1227), then the game itself moves here (#1), then it
learns to run under other BBS software.

The banner is drawn from the game's own launch splash by `art/render_banner.py`
(`python art/render_banner.py war_dialer.py art/banner.png`).
